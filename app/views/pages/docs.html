Documentation

Introduction

Goku is a modern web framework for Go, inspired by the elegance and developer-friendliness of frameworks like Laravel. It provides a solid foundation for building robust and performant web applications with a clean and maintainable structure.

This documentation provides a high-level overview of the framework's key concepts and features.

Project Structure

The framework follows a typical MVC (Model-View-Controller) pattern. The main directories are:

  • /app: Contains the core application logic (controllers, models, services, etc.).
  • /bootstrap: Handles application initialization and bootstrapping.
  • /cmd: Defines the command-line interface (CLI) commands.
  • /config: Stores configuration files.
  • /database: Contains database-related files like migrations and seeders.
  • /middleware: For HTTP middleware.
  • /routes: Where you define your application's routes.
  • /storage: For file storage.

Routing

Routing is handled by the powerful chi router. Routes are defined in routes/web.go.

Here's an example of how to define a route:

// routes/web.go
package routes

import (
    "github.com/go-chi/chi/v5"
    "github.com/your-username/goku-framework/app/controllers"
)

func RegisterWebRoutes(r *chi.Mux, homeController *controllers.HomeController) {
    r.Get("/", homeController.Index)
}

Controllers

Controllers are responsible for handling incoming HTTP requests and returning a response. They are located in the app/controllers directory.

A controller method typically receives a request, interacts with the model or other services, and returns a view.

// app/controllers/HomeController.go
package controllers

import (
    "net/http"
    "github.com/your-username/goku-framework/app/services"
)

type HomeController struct {
    view *services.ViewService
}

func NewHomeController(view *services.ViewService) *HomeController {
    return &HomeController{view: view}
}

func (c *HomeController) Index(w http.ResponseWriter, r *http.Request) {
    c.view.Render(w, "home", nil)
}

Views

Views are located in app/views and are written using Go's standard html/template package. The ViewService helps in rendering these templates.

The framework uses a layout-based approach. The main layout is in app/views/layouts/app.html, and pages define a "content" template.

Models & ORM

Goku uses GORM as its ORM (Object-Relational Mapper), making it easy to interact with your database. Models are defined in the app/models directory.

// app/models/User.go
package models

import "gorm.io/gorm"

type User struct {
    gorm.Model
    Name  string
    Email string `gorm:"unique"`
}

Configuration

Configuration is managed by Viper and stored in config/app.yaml. You can access configuration values throughout your application.

CLI Commands

The framework includes a powerful CLI based on Cobra. You can create your own commands in the cmd directory.

Some of the built-in commands include:

  • go run main.go serve: To start the web server.
  • go run main.go make:controller [name]: To create a new controller.
