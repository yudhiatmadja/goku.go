Installation

1. Prerequisites

Make sure you have Go installed on your system. You can download it from the official website:

https://golang.org/dl/

2. Clone the Repository

Clone the Goku framework repository to your local machine.

git clone https://github.com/gtkm/goku-framework.git
cd goku-framework

3. Install Dependencies

Install the necessary Go modules.

go mod tidy

4. Configuration

Copy the sample configuration file.

cp config/app.example.yaml config/app.yaml

Update config/app.yaml with your database credentials and other settings.

5. Run the Application

You can run the application using the serve command.

go run main.go serve

Your application will be available at http://localhost:8080.
